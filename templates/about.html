About This Project

Cricket Tracker is a stats tracking web app built as a college project. It lets you browse ODI, T20, and Test career stats, search and sort players, view team squads, and check top records — all powered by a Flask backend and SQLite database.

Built by Roshan Yadav, BSc Computer Science, RJ College.
